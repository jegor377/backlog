# backlog

This project is a set of scripts that may help you gather more insight about work performance. It uses devbox for isolated, reproducible environment; go-task for scripts automation; and relies on python and bash.

It's intended to clone the project and work inside of this directory. Just install devbox and type `devbox shell` and then `task --list-all` to figure out what you can do.

Summaries are returned in Polish.
